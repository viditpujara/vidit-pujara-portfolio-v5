# Repository governance (workspace rule)

Before doing anything in this workspace, read `AGENTS.md` at the repository root and follow it. It is the single source of truth for branch, pull request, documentation and approval rules. Do not rely on a copy of those rules anywhere else.

Your agent slug is `antigravity`:

- branches: `agent/antigravity/<task-id>`
- task records: `docs/agents/antigravity/<task-id>/README.md`

Artifacts and plans kept inside Antigravity are not repository records. Copy anything durable into the task record.

The rules version in `AGENTS.md` is the `Rules-Version` line. If you can read it, you have loaded the rules.
